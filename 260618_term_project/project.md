# 목적
가스 환경 데이터를 사용하여 3초 후, 9초 후, 30초 후, 60초 후, 120초 후를 예측할 수 있는 모델을 학습하여 보고서로 제출
포함할 내용 : 데이터셋 구성, 전처리 방법, 모델 구성, 학습 방법, 성능 평가

# 시계열 데이터 구성
- 6개 데이터셋으로 구성되며 각 데이터셋은 1000개의 에피소드로 구성됨. 즉 6개 데이터셋 * 1000개 = 총 6000개 데이터
    - Pressure_1:압력 센서 값
    - Pressure_2:압력 센서 값(1과 다른 위치)
    - Temperature_1:온도 센서 값
    - Temperature_2:온도 센서 값(1과 다른 위치)
    - gas leak: 누수된 가스 농도 
    - Accelerometer: 가속도 센서 값 (배관 진동 정도 )
- 하나의 데이터 파일에는 100ms 단위로 300초동안 값이 기록됨
- 같은 시점의 6개의 데이터를 하나의 튜플로 사용할 것. 즉, 6개의 속성을 하나의 입력값으로 사용
- 파일명 끝에 적힌 번호가 같은 데이터들은 같은 시점에 기록된 데이터
- 파일명 끝에 적힌 번호가 다른 데이터들은 서로 상관없는 데이터
- png 파일은 무시할 것

# 요구사항
- 사용 가능 신경망 하나 당 하나의 파일을 만들어 각 신경망 별도로 학습 시킬 것.
- 예측 시간 5가지(3초 후, 9초 후, 30초 후, 60초 후, 120초 후)에 대한 모델 학습 코드도 각각 생성할 것.
- 각 모델 당 폴더를 하나 만든 후 예측 시점마다 파일을 생성할 것.
- 2가지 모델 * 5개 시점 = 총 10개의 파일을 생성할 것.


# 주의사항
- 데이터셋 마다 스케일이 다르기 때문에 전처리가 중요함.
- 파일명 끝에 적힌 번호가 다른 데이터들은 서로 상관없는 데이터이기 때문에 해당 데이터들을 연속시켜서 학습하면 안됨. (이 부분 해결 방법을 제안할 것.)
